# 트리파논 (TRYPANON) · 지구를 뚫어라

양구 국토정중앙에서 출발해 지구 중심까지 드릴로 뚫어 내려가는 방치형 모바일 시추 게임입니다.

## 실행 방법
- `index.html` 파일 하나로 동작합니다. 브라우저로 열면 바로 플레이할 수 있어요.
- 저장은 브라우저 저장소(localStorage, 키 `trypanon-save-v1`)에 됩니다.

## 주요 시스템
- 본공: 지각 → 맨틀 → 외핵 → 내핵까지 자동 굴착, 엔딩 3종(새 회차)
- 원정: 명산 10곳 · 바다 4곳에서 재료 채굴, 지형별 유물·화석
- 제작: 부품 10종, 드릴 Lv.1~100 (현재 50까지 개방)
- 창고 / 상점(재료 사고팔기) / 투자자
- 내 땅: 집·정원·반려동물, 집 안 꾸미기(층·가구 배치), 화석관·유물관

## 폴더 구조
```
index.html   게임 전체 (HTML + CSS + JS 한 파일)
README.md    이 문서
```

## GitHub Pages로 폰에서 테스트하기
저장소 Settings → Pages → Branch: `main` / 폴더 `/ (root)` → Save.
잠시 후 `https://<아이디>.github.io/<저장소이름>/` 주소로 접속할 수 있어요.
