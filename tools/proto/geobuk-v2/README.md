# 한국 특수 영웅 거북선 3D 시안 (v384 시점, 게임에는 아직 안 들어감)

- `ship2.js` — `tsShipPro()`: GPT가 만든 랜드마크 청동 거북선(`lmBronzeShip2`)을 바탕으로 채색. 높인 철갑 지붕(가시), 단청 띠, 총통, 노걸이·노깃이 있는 젓는 노(`userData.tick`), 돛 2개와 깃발.
- `dragon.js` — `tsDragonHead()`: SDF로 깎은 채색 용머리(이빨·혀·금빛 눈·뿔·갈기·수염).
- `render.py` — 지금 거북선(`s3Ship`)과 시안을 바다 위에서 비교 촬영 → `out/ship_mock.png` (proto 폴더에서 실행하도록 쓴 스크립트).
- 사용자 승인 뒤 `s3Ship` 자리에 넣을 것. 크기는 지금 배의 약 1.3배라 카메라·배치 조정이 필요하다.
